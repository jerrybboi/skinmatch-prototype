# skincare-prototype

A properly scaffolded Next.js starter for the personalized skincare V1 project.

## Current course stage
This repository is the foundation for later lessons. It intentionally contains the basic Next.js application scaffold and a simple starting screen. The full assessment, Supabase, authentication, product catalog and AI recommendation work will be added in later lessons.

## Product journey
Register → choose region → guided skin scan → questionnaire → skin profile → region-aware product recommendations → optional routine.

## Stack
- Next.js
- Supabase (to be connected in later lessons)
- GitHub
- Vercel
